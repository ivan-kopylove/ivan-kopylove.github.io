Implemented the microservices for an antifraud department.

Microservice 1: an active-active parallel adapter for multiple bi-directional (RabbitMQ <-> REST) integrations. 

Microservice 2: processes incoming requests from antifraud inter-company bus - collects data from 6 microservices, applies bussines logic and produces the result back to the bus.

Repetitive practices:
- proactively clarified missing requirements with the analyst and the product owner;
- deployed to prod once a week (using Green-Blue deployment + canary) using screen;
- DEVOPS: linux (screen, htop, curl);
- addressed erroroneus logs from opensearch;

- Spring boot 3 + Java 21 (+ concurrency API);
- junit, Spring boot test, testcontainers, Mockito, Wiremock;
- RabbitMQ
- Spring (core, web, AOP), resilience4j;
- Docker compose;
- SQL via Posgres 17, liquibase, hibernate;

- jobrunnr
